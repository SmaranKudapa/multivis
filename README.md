# Multivis

Multivis is an interactive visualizer for multivariable calculus. Type a
double or triple integral in LaTeX, and see it rendered as proper math
notation alongside a 3D graph of the region or solid it describes.

> **Status:** early development. The project is being built incrementally —
> this README grows alongside it.

## Running it locally

```bash
npm install
npm run dev
```

Then open the local URL Vite prints in your terminal.
